Slide 03 — Our Solution

GridWise AI — What We Built

IBM
BoB

A complete, interactive, AI-powered web platform for electricity-grid decision support — addressing all 5 dimensions of Problem U2.

📊

Demand Forecasting

Weighted Moving Average with hour-of-day, day-of-week, and temperature factors. Confidence intervals ±4% → ±13% over 24h. Automatic spike detection alerts.

☀️💨

Renewable Monitoring

6 asset fleet (3 solar, 3 wind). Z-score and threshold anomaly detection. Automated root-cause analysis with ranked probable causes and recommended actions.

⚖️

Grid Balance

Real-time surplus/deficit gauge. Reserve margin monitoring (target ≥8%). Generation mix donut chart. Risk period timeline with formula display.

🤖

AI Insights

Rule-based chatbot answering 20+ question patterns. Demand narrative, anomaly explanation, load-balancing recommendations — all data-driven and transparent.

✂️

Curtailment Optimisation

Formula: max(0, Available − Utilised). AI minimisation plan with 4 strategies: flex load (55%), storage (25%), interconnector (15%), conventional reduction.

📋

Operator Brief

One-click 9-section structured report (A–I). Executive summary, demand forecast, renewable performance, grid balance, root causes, recommendations, curtailment plan, outlook. Printable PDF.

Slide 05 — AI Capabilities

Transparent Rule-Based AI

IBM
BoB
No Black-Box Models Fully Explainable No API Keys Required

📈 Demand Forecasting

forecasting.js
Weighted Moving Average of historical periods at same hour
Hour-of-day factor table (24 values) × Day-of-week factor (7 values)
Temperature adjustment: +3% per -10°C below 18°C heating baseline
Confidence intervals widen ±4% → ±13% over forecast horizon

🔍 Anomaly Detection

anomalyDetection.js
Z-score method: Flag if |z| > 2.5 — statistical outlier detection
Threshold method: Flag if actual < 70% of expected output
Applied to solar, wind, and demand independently
Output: severity, deviation%, Z-score, type, probable causes

🧠 Root Cause Analysis

aiInsights.js
7 solar cause library ranked by deviation magnitude + probability estimate
7 wind cause library with recommended verification steps
Output: natural-language explanation + ranked probable causes + actions

✂️ Curtailment Analysis

calculations.js
Formula: Curtailment = max(0, Available Renewable − Utilised)
Recovery modelling: 55% flex load + 25% storage + 15% interconnector
High-curtailment period identification and asset breakdown

💬 AI Chatbot

answerQuestion()
10 keyword patterns matching demand, solar, wind, curtailment, anomalies, recommendations, forecast, balance, carbon, reserve margin
Every response interpolates live KPI values — no static text
