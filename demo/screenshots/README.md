## How to Capture Screenshots

### Windows:
1. Run `npm run dev` in Command Prompt
2. Open `http://localhost:5173` in Chrome or Edge
3. Navigate to each page
4. Press `Win + Shift + S` to capture a region
5. Save each screenshot with the filename from the index above

### Mac:
1. Press `Cmd + Shift + 4` to capture a region
2. Save each screenshot with the filename from the index above

### Browser Extension:
Use "Full Page Screen Capture" or "GoFullPage" Chrome extension for full-page screenshots.
